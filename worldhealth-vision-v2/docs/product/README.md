## Contrat produit constant

- **International** dès l'architecture : pays/territoires, sources nationales/régionales/internationales, devises, fuseaux, langues, licences et couverture explicitée.
- **Utile au quotidien** : surveillance de tarifs, alertes, budgets réels, comparaisons de magasins, frais nets de transfert, calendrier Forex, données boursières sous licence, géographie et radar d'événements.
- **Prouvé avant vendu** : `catalogued` n'est pas `ingested` ; `signal` n'est pas `fact` ; `reference-rate` n'est pas `transfer-fee` ; `indicative-price` n'est pas `bookable-offer`.
- **Revenus responsables** : affiliation identifiée et sans classement biaisé, abonnements basés sur automatisation fiable, publicité proportionnée, API B2B sans redistribution abusive.
- **Production par étapes profondes** : parcours complet fonctionnel + tests + documentation + logs + métriques + coûts avant d'ajouter une nouvelle verticale. Préserver V2 et les décisions média.
