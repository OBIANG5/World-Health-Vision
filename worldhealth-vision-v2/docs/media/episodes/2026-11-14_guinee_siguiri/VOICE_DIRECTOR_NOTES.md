# World-Vision — direction vocale scène par scène : Siguiri (14/11/2026)
**La voix est un métier de mise en scène, pas un paramètre « speed ».** Seul le fichier `SCRIPT_LOCK_V1.json` fait autorité pour les mots. Cette fiche décrit l'intention, jamais une réécriture. La voix Vivienne est un timbre préféré par l'utilisateur, NON une prise finale approuvée ou une licence commerciale. Toute personne/narratrice alternative doit respecter exactement le même texte.

## Retour propriétaire à intégrer à TOUS les futurs épisodes
La vidéo précédente publiée sur le Soudan du Sud obtient **4–5/10**. Une intonation plate, débit trop rapide, absence de chaleur, images génériques. Désormais mesurer le débit; ne pas accélérer la voix pour réduire le métrage ; viser **125–150 mots/minute**, avec respirations authentiques. Une vraie présence humaine prime sur le respect d'une durée arbitraire. Pour la Guinée, la limite est **60 secondes** et le texte a **109 mots**.

## Méthode de prise vocale
- Préparer deux auditions **avec des mots strictement identiques**, différant seulement par l'énergie et la durée des pauses. Pour les outils qui prennent SSML prosody/style : utiliser les styles uniquement s'ils sont **réellement disponibles/licenciés**. Les ajustements du client non officiel edge-tts ne suffisent pas à produire une véritable émotion humaine.
- Dans le premier montage de recherche, Vivienne est ralentie par rapport à V3 sans compression a posteriori, chaque phrase est synthétisée séparément pour permettre des respirations naturelles. **Le débit et les pauses réels sont consignés dans manifest.json.**
- Pas de musique à volume dominant ; pas d'effet de tirs ni de fausses sirènes ; priorité à l'intelligibilité de chaque mot.
- Avant de publier : écouter le clip entier dans la vraie appli iPhone avec et sans écouteurs ; vérifier accent, coupures, monotonie, micro-silences, niveau sonore, toutes les dates et noms ; conserver la note propriétaire. Les indicateurs techniques ne peuvent pas attribuer une bonne note artistique.
- Droits : Microsoft n'autorise explicitement la sortie commerciale des voix neuronales prêtes à l'emploi qu'avec le service TTS payant compatible (vérifier disponibilité exacte de Vivienne), pas automatiquement par un accès Edge TTS expérimental. Remplacer l'essai avant usage commercial selon les conditions applicables.
